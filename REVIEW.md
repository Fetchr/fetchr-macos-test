## Критично (безопасность)

1. **Приватный ключ лицензий закоммичен** — `scripts/license-keygen.mjs:8` (Ed25519 PRIVATE KEY в открытом виде). Любой с доступом к репо генерирует валидные ключи.
   Фикс: новая пара ключей, перевыпуск лицензий, приватный ключ только в env на VPS, заменить `PUBLIC_KEY_BASE64` в `license.rs:10`. Удаление из файла не поможет — ключ в истории git.

2. **`install_update` запускает произвольный exe** — `updater.rs:124–174`. Команда принимает любой `installer_url` из фронтенда (http допустим), `sha256` опционален, после скачивания файл сразу запускается. TLS-pin (`remote.rs:47–58`) действует **только** для хоста API — для любого другого хоста `verify_tls_pin` молча возвращает `Ok`. При XSS в webview это RCE.
   Фикс: бэкенд сам берёт URL+sha256 из последнего ответа `check_for_update` (хранить в state), sha256 обязателен, только https.
